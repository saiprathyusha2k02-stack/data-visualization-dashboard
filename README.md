# Data Visualization Dashboard

## Project Overview

This project demonstrates data visualization and exploratory analysis using Python.

The project uses Pandas, Matplotlib and Seaborn to analyze restaurant billing and tipping data.

## Objectives

- Analyze the dataset
- Create meaningful visualizations
- Identify patterns and trends
- Present insights clearly
- Build a portfolio-ready data visualization project

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- GitHub

## Visualizations

The project includes:

- Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot
- Box Plot

## Key Analysis

The analysis explores:

- Average total bill by day
- Lunch vs dinner distribution
- Distribution of total bills
- Relationship between total bill and tip
- Differences in spending across days
